# YouTube Action Map

A small template for deciding when a channel needs attention. Experiment focus: make useful content and progressively reduce routine manual work.

## E0 — First video

**Focus:** Publish the first representative video. The owner or a responsible person can make it semi-manually with AI assistance, saving reusable code as they go. An existing suitable public video can count; do not recreate completed work.

**Trigger:** At least **10 valid public channel views in the last 30 days**, to finish E0 and enter E1.

**Action:** Choose one useful next task from the [YouTube Playbook](../playbooks/youtube.md), based on what is currently holding the channel back.

## E1 — Second video and repeatable production

**Focus:** Make the second video and prepare the code to automate as much of its production as practical. Reuse an existing working engine instead of rebuilding it.

**Trigger:** At least **100 valid public channel views in the last 30 days**, to finish E1.

**Action:** Choose one improvement from the [YouTube Playbook](../playbooks/youtube.md): address the clearest content or production bottleneck first.

## When to act

- **Trigger reached:** Review the completed work and choose the next step. Views alone do not mark unfinished work complete.
- **30 days without reaching it:** Review once and select one change to test. Count this review interval from stage entry or the last review; the views metric always uses the rolling last 30 days.
- **Publishing or measurement breaks:** Investigate and restore it. Missing data is unknown, not zero.

Keep the selected task and its result in the channel's existing plan, not here. Measure aggregate valid public channel views from a healthy, dated source; never buy or manufacture views. Public videos still need ownership, rights and safety checks.

This template stops at E1. After E1, review the evidence before defining more stages. Graduation is separate: real settled, channel-attributable external revenue and explicit owner approval; estimated revenue or views alone never qualify.

This is a new lightweight reference, not an automatic migration of an existing blueprint, plan or recorded level. Adopt it deliberately per channel, preserving verified work and evidence.
